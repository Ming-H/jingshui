# 设计:静水 skill 增加财报分析功能

日期:2026-08-15
状态:已确认

## 背景

skill 现有功能为静水2008 的选股方法论问答(源自 202 条知乎内容,重爬管道持续更新)。
静水自 2026 年中报季开始在知乎连载「财报/中报预告记录」系列(截至 08-15 已 4 篇:
松发股份、药明康德、昭衍新药、中远海特),形成了一套高度固定的财报分析框架。
用户需要一个能对单只标的产出静水式财报分析的功能。

## 决策

**单 skill + 渐进式加载(方案 C)**,而非拆成两个 skill。

理由:财报分析是静水选股体系在单只标的上的"执行动作"——40% 增速阈值、量价齐升、
供不应求等判据两边同源,拆开会导致方法论两处复制、场景割裂(分析完财报必然要回
答"过不过静水的筛选清单")。尺寸问题用 references/ 子文件按需加载解决。

与既有生态的分工:

| 工具 | 职责 |
|---|---|
| tenscreener / can-slim | 全市场漏斗筛选(上游) |
| cninfo-disclosure | 财报 PDF 下载(巨潮/HKEX)+ 券商研报清单(机构一致预期) |
| hithink-finance-query | 历史财务指标(增速趋势验证) |
| **jingshui(本 skill)** | **单标的财报深度分析 + 方法论问答(下游)** |

## 结构

```
jingshui/
├── SKILL.md                    # 功能路由 + 选股方法论(现有,增量优化)
├── references/
│   ├── 财报分析框架.md          # 六段式模板 + 分析口径 + 数据获取工作流
│   └── 财报范例/               # 4 篇静水原文(few-shot)
├── 原文索引.md / scripts/ / README.md / LICENSE   # 现有
```

### 第一部分:选股方法论(SKILL.md 增量优化)

- 结构不变,融入 2026-08-07 以来 6 条新内容的方法论增量:
  - 技术分析的底层逻辑支点是基本面(08-15)→ 补强"雷区-技术分析"
  - "一切能力培养都是为了识别并驾驭超级成长股"=第一性原理(08-11)→ 核心理念
  - "没有超级成长性就没有超级上涨"、财报寻找法是价值投资人最常用路径(08-07)→ 核心理念/财报选股法
  - 财报记录系列连载本身 → 每日功课一节点明并链接第二部分
- 来源统计更新为 196 回答 + 6 文章 = 202 条(2026-08-15)

### 第二部分:财报分析(references/财报分析框架.md)

**数据获取工作流**(按输入分支):PDF 路径直接读;公司名/代码 → cninfo-disclosure
下载正本;增速趋势 → hithink-finance-query 近 4-8 季;机构预期 → cninfo 研报清单;
承接 tenscreuner L2 结论补财报验证。

**静水分析口径**:倒推单季;剔一次性损益(归母 vs 扣非背离拆解);β/α 分离;
订单验证(在手订单 > 当期利润);关键词捕捉映射选股清单。

**输出六段式**:一、业绩记录;二、业绩增长原因;三、未来发展逻辑;四、潜在风险;
五、总结;六、静水筛选清单结论(核心因子 7 条 + 5 不买逐条核对 → 过/不过);
免责声明(静水固定格式)。
