## 一、分析口径(静水区别于普通财报解读的关键手法)

以下 5 个手法在 4 篇范例中反复出现,必须逐一体现在报告中:

### 1. 倒推单季
用累计值倒算最新单季的环比 / 同比,判断利润释放节奏。
范例:松发股份——由 H1 预告 + Q1 实绩倒推 Q2 单季归母约 25.07 亿,环比 +129%、
同比 +538%,得出"Q2 贡献上半年近七成、利润释放明显提速"的结论。

### 2. 剔一次性损益
归母增速与扣非增速明显背离时,必须拆出非经营性贡献(公允价值变动、股权出售、
政府补助等),回答"利润是不是真的"。
范例:昭衍新药——扣非 +2334%~3551% 貌似爆炸,拆解后 7~7.8 亿来自实验猴生物资产
公允价值重估,实验室主业仍在亏损至微利区间。

### 3. β / α 分离
先讲**行业 β**(周期位置、供需格局、价格趋势),再讲**公司 α**(订单结构、产能释放、
一体化降本)。两者分开归因,不混为一谈。
范例:松发股份——β 是全球造船超级周期(新接订单 +123.8%),α 是船型结构升级
(高附加值船占比抬升) + 发动机自供 + 批量化生产摊薄成本。

### 4. 订单验证(前瞻判据 > 当期利润)
在手订单、新签订单增速、交期排程比当期利润更重要——订单是未来收入的可见度。
范例:药明康德——在手订单 664.3 亿(+25.2%)已超过全年指引上限;昭衍新药——
新签 +111.6%、在手 +40.9%,主业真实的拐点信号来自订单端而非账面利润。

### 5. 关键词捕捉 → 映射选股清单
从财报 / 公告 / 调研纪要中捕捉:供不应求、量价齐升、排产满负荷、下游排队、
涨价、超预期——每个命中直接对应 SKILL.md 核心因子与识别清单。
范例:中远海特——PCC 运价 Q2 5.4 万美元/天、6 月升至 6 万,运力 +36.6%、
货量 +56%,标准"量价齐升"。

## 二、数据获取工作流(按输入分支)

| 用户输入 | 动作 |
|---------|------|
| 给了财报 PDF 路径 | 直接读 PDF(用 Read 工具,分页读),跳到分析 |
| 只给公司名 / 代码 | 调 **cninfo-disclosure** 技能下载最新财报 / 业绩预告正本(自动排除摘要、更正版、H 股版) |
| 需要验证增速趋势 | 调 **hithink-finance-query** 拉近 4–8 季营收 / 利润序列,判断"加速 / 减速 / 拐点" |
| 需要机构一致预期(第五段可选) | 调 **cninfo-disclosure** 的券商研报清单(评级 / 分析师 / 盈利预测) |
| 标的来自 tenscreener 筛选 | 承接其 L2 体检结论,本分析作为财报维度的深度验证补全 |

注意:
- 业绩**预告**与正式**财报**口径不同:预告只有区间,要用中枢值测算并倒推单季;正式
  财报则逐项拆分业务收入。
- 静水本人坚持亲自读原文、不信二手总结——原则上以公告原文为准,MCP 数据只作交叉验证。
- 数据来源与报告类型必须在开头注明。

## 三、输出格式(固定六段式 + 清单结论)

严格按以下模板输出,标题层级、编号习惯、口吻对齐 `财报范例/` 中的原文:

```markdown
# {公司名}({报告类型}分析)

> 数据来源:{公告名 / 巨潮资讯 / 用户提供的 PDF 等}　|　分析框架:静水2008 财报记录体系
> 声明:非投资建议,仅供参考学习。

## 一、业绩记录
- 营收 / 归母净利 / 扣非净利:绝对值 + 同比增速(表格呈现)
- 预告类:取中枢测算;倒推最新单季环比 / 同比,判断利润释放节奏
- 扣非 vs 归母增速对比 → 初判盈利质量

## 二、业绩增长原因
- 行业 β:周期位置、供需格局、价格趋势(运价 / 订单 / 涨价周期等)
- 公司 α:订单结构、产能释放、一体化降本、规模效应
- 若有一次性损益:明确拆出并量化其贡献

## 三、未来发展逻辑
- 在手订单 / 新签增速 / 交期排程(业绩可见度)
- 产能扩张与释放节奏
- 管理层指引(上调 / 维持 / 下调)与资本开支信号
- 天花板:所处是否当下时代核心产业趋势(SKILL.md「各时代主线」对照)

## 四、需要关注的潜在风险
- 冷静拆解前瞻变量(收入依赖、价格回落、债务、周期见顶信号等)
- 每条风险注明"看什么指标来跟踪"

## 五、总结
- 增长质量一句话定性(真成长 / 重估驱动 / 周期馈赠)
- 后续需跟踪的 2–3 个关键变量

## 六、静水筛选清单结论
### 核心因子 7 条(逐条 ✓ / ✗ / 部分)
1. 营收利润增速 ≥ 40%:
2. 新产品 / 新服务 / 新市场量价齐升:
3. 管理层对产业趋势强烈认同:
4. 当下时代核心产业趋势中的超级 α:
5. 逻辑无法证伪、越推演越明朗:
6. 符合机构选股偏好:
7. 政策大力扶持的第一核心行业:
### 5 不买负面清单(一票否决,逐条核对)
1. 亏损公司? 2. 主营增速 < 40%? 3. 未创一年新高? 4. 无新产品 / 新市场? 5. 无强供求矛盾?
### 结论:**过 / 不过 / 部分通过(差哪几条)**

(可选)机构一致预期与估值:一致预期净利 / 目标价 / 动态 PE

免责声明:本文仅代表个人观点,不构成任何形式的有价证券推荐、投资决策建议或承诺。
市场有风险,投资需理性,读者切勿依据本文内容作为买卖依据,务请结合自身风险偏好独立判断。
```

### 口吻与风格要点(对齐范例)
- 编号习惯:"一、二、三…"大章节 + "1、2、3…"小点,直接、干脆。
- 增长原因部分喜欢在段末用括号点睛,如"(运价↑)""(新能源出海↑)""(量价齐升)"。
- 客观拆分:既写"预告客观上看质量很高",也写"需冷静看待变量"——不是无脑吹。
- 免责声明用静水固定格式(见模板末尾),不可省略。
