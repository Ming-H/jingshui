## 1. 财报季日课 SOP（每年 1、4、7-8、10 月，每日约 60-90 分钟）

静水原文工作要求："在每天出业绩的成长股里不落下任何一只潜在的超级成长"（2026-10-08）。日课就是这句话的流程化：

| 步 | 动作 | 工具/命令 | 输出 | 耗时 |
|---|------|----------|------|------|
| 1 | 拉当日披露清单（含增速） | `eastmoney-data: python3 scripts/cli.py --list <日期>` | 当日披露公司列表 | 5 min |
| 2 | **40% 闸门过滤**：只留营收或利润增速>40% 者（预告取中枢，算法见 §2.2） | 上表直接含增速列 | 闸门通过名单（通常每日 0-10 家） | 10 min |
| 3 | **倒推单季**：算最新单季同比/环比 | 公式见 §2.1 | 单季序列 | 10 min |
| 4 | **六判别**：逐条过 §3 判定表 | cninfo 下载原文 PDF 精读 | 每家 6 个标签 | 20-30 min |
| 5 | **定性快筛 3 问**（§4.1），通过者再做完整 10 问 | 财报原文+调研信息 | 定性结论 | 10 min |
| 6 | **比较定位**：当批全部合格者填入 §5 矩阵 | — | 当批排名 | 5 min |
| 7 | **三档标签入库**（§1.1）+ 记录 | §9 模板 | 观察池更新 | 5 min |

**非财报季节奏**：每周扫一次持仓与观察池的最新公告/调研纪要；每天复盘一只历史大牛股（§6）。

### 1.1 三档结论标签（静水日报的标准输出，2026-10 系列）

对每家闸门通过的公司，最终只落三个标签之一：

| 标签 | 含义 | 触发条件 |
|------|------|---------|
| **参与** | 进入介入流程 | 六判别全过 + 定性 10 问≥8 + 比较矩阵当批前 1-2 名 |
| **只跟踪** | 进观察池，每季复核 | 六判别过但比较落后 / 预期已打满 / 板块处于反弹浪而非主升 |
| **阅** | 记录后不再投入精力 | 触发任一判别否决（周期修复、水分、跟班地位等） |

静水原文高频表述对照："参与 / 只跟踪不妄动 / 阅"。

## 2. 定量操作：门槛与公式

### 2.1 单季倒推（累计值差值法）

```
单季营收(Qn) = 累计营收(至Qn) − 累计营收(至Qn-1)
单季净利(Qn) = 累计净利(至Qn) − 累计净利(至Qn-1)
环比增速(Qn) = 单季(Qn) / 单季(Qn-1) − 1
同比增速(Qn) = 单季(Qn) / 单季(Qn 去年同期) − 1
```

注意：Q1 直接用一季报累计值；年报 Q4 = 全年 − 前三季。工具：`eastmoney-data --quarterly <股名>` 直接返回近四季单季（东财口径）。

### 2.2 预告中枢值算法（业绩预告只有区间时）

```
中枢净利润 = (预告下限 + 预告上限) / 2
同比增速(中枢) = 中枢净利润 / 上年同期净利润 − 1
单季中枢 = 中枢累计 − 已披露的前几季实绩之和
```

范例（松发股份，中报预告）：H1 预告中枢约 28.3 亿 − Q1 实绩 3.2 亿 = **Q2 单季约 25.07 亿**，环比 +129%、同比 +538% → "利润释放明显提速"。

### 2.3 定量门槛总表

| 门槛 | 标准 | 数据源 | 一票否决? |
|------|------|--------|----------|
| 营收增速 | 单季或预告中枢同比 >40% | 东财/问财/预告原文 | 是（5 不买第 2 条） |
| 利润增速 | 同上 >40% | 同上 | 是 |
| 盈利状态 | 当期盈利（亏损直接出） | 同上 | 是（5 不买第 1 条） |
| 创新高 | 股价创一年新高或距高点<20% | 东财 --stock（pct_of_high 字段） | 是（5 不买第 3 条） |
| 环比动能 | 最新单季环比为正或持平 | §2.1 自算 | 否（六判别第 2 条） |
| 绝对量级 | 利润绝对额与自身历史巅峰可比（防低基数，§3 判别 3） | 东财 --stock | 否 |

**优先级**：营收利润双 40% > 仅利润 40%（要查是否靠削减成本/非经）> 仅营收 40%（利润未跟上，可能是投入期，转入定性重点查）。

## 3. 六判别操作判定表（核心工具）

对每家通过闸门的公司逐行填表。每条判别给出：判定问题、看什么数据、否决/放行标准。

| # | 判别 | 判定问题 | 看什么（数据源） | 否决标准 |
|---|------|---------|----------------|---------|
| 1 | 周期修复 vs 成长逻辑 | 增长主要靠**涨价**还是靠**技术迭代/产能爬坡/产品结构升级/新品放量**？ | 财报"增长原因"段；产品价格数据；毛利率结构（涨价型=毛利率随价格同步波动；成长型=毛利率结构性抬升） | 增长原因只有"产品价格上涨/价差修复/行业回暖"，无新品/新产能/结构升级 → 标"周期修复"，结论"阅" |
| 2 | 环比动能 | 最新单季环比还在加速吗？ | §2.1 自算环比序列 | 环比停滞或转负（如德明利 +2%）→ 标"红利见顶"，至少降档为"只跟踪" |
| 3 | 低基数/扭亏水分 | 倍数级增速的基数是多少？绝对额处于自身历史什么位置？ | 东财 --stock（net_profit 历年值） | 去年同期亏损或微利 → 增速数字不可用，改用绝对额对比历史巅峰（如不足巅峰 1/3 → 折价处理） |
| 4 | 原料顺价水分 | 上游涨价年份（存储/铜/稀土等），利润里有多少是囤料价差？ | 财报/调研中"剔除原材料影响"表述；毛利率与原料价格的相关分解 | 无法剥离且公司处于涨价原料行业 → 定性降半档；有"剔除后毛利率仍+Xpct"表述 → 用剔除后数字做定性 |
| 5 | 预期打满/利好兑现 | 业绩超预期但市场反馈如何？（财报次日与一周股价） | 行情工具看披露日前后涨跌 | 业绩大超预期但股价不涨/下跌 → 标"预期打满"，报告结论必须分开写"业绩评价"与"市场反馈评价" |
| 6 | 一眼定胖瘦 | 它是这条产业链**最核心受益者**吗？ | 产业链地图（谁拿走最大价值增量）；营收/利润弹性对比同行 | 是核心 α 的跟班/配套（如思瑞浦之于光模块"易中天"）→ 结论"做核心不做跟班"，标"阅" |

**附加判别 7（产业阶段）**：所在行业是否出现"二线集体超预期新高、一线龙头涨不动"？是 → 整条链定性为**后排受益期=产业后期**，只按反弹浪对待（介入仓位减半、不按新主升对待）。

**输出格式**（每家公司一行）：

```
[公司] 判别: ①成长✓ ②环比+15%✓ ③绝对额创高✓ ④无顺价✓ ⑤市场正反馈✓ ⑥核心α✓ | 产业阶段:主升中 → 三档标签: 参与/只跟踪/阅
```

## 4. 定性分析：10 问清单（三维分析法第 2 维）

静水原文（2026-10-13）："用你过去所有的商业经历，判断它的商业模式、盈利、增速是否可持续、是否有确定性。" 操作化为 10 问，≥8 个"是"通过：

### 4.1 快筛 3 问（日课用，30 秒/家）

1. 增长的钱从哪来——新客户/新产品/新产能/提价，能说清一句话吗？
2. 这个驱动力**明年还在吗**（订单能见度/产能爬坡空间/价格可持续性）？
3. 竞争对手为什么抢不走（份额、壁垒、卡位）？

### 4.2 完整 10 问（"参与"级标的用）

| # | 问题 | 证据来源 |
|---|------|---------|
| 1 | 商业模式一句话说得清吗（谁付钱、为什么付、复购吗）？ | 财报主营构成 |
| 2 | 新产品有大量实际客户、可大量复刻吗（新品三问之 1）？ | 财报+调研 |
| 3 | 新业务现金流占母公司利润比重够大吗（占比过低无意义——茅台冰淇淋反例）？ | 分部数据 |
| 4 | 在手订单/新签订单增速支撑未来 2-4 季收入吗？ | 财报订单披露 |
| 5 | 产能释放有明确时间表吗（爬坡坡度可算）？ | 公告/投纪要 |
| 6 | 是当下时代核心产业趋势的第一受益层吗（不是第二层跟班）？ | 产业对标法 |
| 7 | 供给端有约束吗（产能建设周期/资源独占/认证壁垒）——强供求矛盾在吗？ | 行业供需 |
| 8 | 管理层在调研/纪要里对产业趋势强烈认同并 all in 吗？ | 调研纪要 |
| 9 | 逻辑能被证伪吗——最可能的证伪事件是什么、何时检验？ | 自建反例 |
| 10 | 符合机构审美吗（体量、流动性、赛道 Story）——有资金来抬轿吗？ | 公募持仓 |

**配套调研动作**（成长选股法，普通人版）：对消费类标的做线下验证——门店排队/爆火/复购观察（万辰案例：财报发现业绩爆发 + 一二线城市门店全爆满 = "生意简单可复制"验证通过）。

## 5. 比较分析矩阵（三维分析法第 3 维）

静水原文（2026-10-13）："一个时段市场往往同时出现多个超级成长股，必须比较出持续性最佳、确定性最强的一两个。" 当批全部"参与/只跟踪"标的填入：

| 维度 | 权重 | 标的A | 标的B | 标的C |
|------|-----|-------|-------|-------|
| 增速高度（单季同比/环比） | 高 | | | |
| 增速质量（六判别通过数） | 高 | | | |
| 产业地位（核心 α or 跟班） | 高 | | | |
| 业绩可见度（订单/产能排程） | 中 | | | |
| 市场认可度（新高/抗跌/资金） | 中 | | | |
| 想象力（天花板与辨识度） | 中 | | | |
| 估值弹性（市值空间/拥挤度） | 低 | | | |

**判定**：综合前 1-2 名进入介入流程；其余降为"只跟踪"。**切记：好机会是显见的**（好机会两条件）——需要反复论证才能垫到第一名的，降档。

## 6. 历史大牛股复盘 SOP（修炼课，非财报季每日一课）

静水原文（2026-10-13）："把历史大牛股找出来，逐季看财报，并结合走势观察市场对财报的反馈。每天复盘一只，坚持一年。"（他认为这是培养定性能力最快的路径）

单只复盘流程（60-90 分钟/只）：

1. **选标的**：历史十倍股任选（宁王/天赐/泡泡玛特/万辰/光王/汾酒…），按时代主线顺序过
2. **拉全程季报**：起点=主升浪启动前 2 年，终点=见顶
3. **逐季记录双线**：每季"业绩线"（增速/环比/超预期与否）×"市场线"（财报披露日前后股价反应）
4. **标注三个关键点**：
   - 最早可发现点：哪份财报第一次出现 40%+ 且六判别全过？（回测自己会不会抓到）
   - 最佳介入点：发现点之后哪次回调？
   - 见顶信号点：增速/环比/订单哪项最先掉队？股价从该季财报后多少天见顶？
5. **提炼一句**：这只股票的"一眼定胖瘦"特征是什么（普通人当时能看到什么）
6. **归档**：写入个人复盘库；跑满 50-100 只后自然形成定性硬标准

## 7. 介入执行：10 份规则参数化

静水原文（2026-07-25 最强模型的资金管理，参数固定）：

| 参数 | 值 | 说明 |
|------|-----|------|
| 总资金切分 | 10 份 | 每份=总资金 10% |
| 单标的首次买入 | 1 份 | 识别通过 + **等到回调**后分 2-3 批建完 |
| 加仓触发 | 浮盈 +100% 时加 1 份 | "翻倍后加 1 份"（浮盈加仓，与摊平反着来） |
| 单标的上限 | 2 份（20%） | 无论如何不破 |
| 目标 | 10 倍 | "对了死拿，拿到基本面不行了再卖" |
| 止损 | 逻辑看错即砍 | 不设价格止损设逻辑止损；新手可用固定点 |

**红线**：不加杠杆、不单吊（满融单吊药明的爆仓案例是作者反复引用的反面教材）。

**介入时机补充**（2026-10 系列）：指数阶段底部 + 反弹浪预期时，主攻"反弹浪 5 条件"标的（高速成长性/高度确定性/业绩超预期/辨识度依旧/非常有想象力）。

## 8. 持有期跟踪与退出触发

### 8.1 每季复核（财报披露日必做，用《财报分析框架.md》六段式）

核对三件事：
1. **增速还在吗**：单季同比/环比仍 >40% 且未触发六判别否决？
2. **市场反馈**：财报后股价反应（预期是否打满）？
3. **逻辑变化**：证伪事件（定性 10 问第 9 条预设的）发生了吗？

### 8.2 退出只有两个条件（2026-09-20）

| 条件 | 判定 | 动作 |
|------|------|------|
| ① 更好的成长股出现 | 新标的比较矩阵显著优于持仓（非小幅） | 逐步挪仓（旧标的最理想在衰败同时新标的被发现） |
| ② 当下成长股基本面景气度下降 | 增速掉出 40% 区/订单转负/证伪事件发生 | 退出，"市场永远比基本面快一步"，接受已发生的回撤 |

**错误处理**：买完发现逻辑看错（不是回调是衰退）→ 发现即砍，不分批不侥幸。

**心理预期管理**（原文）：超级成长股常经历 2 次 30-40% 中期调整、单票可能腰斩；十倍股一般只赚到五六倍——"理解并接受这一点才算合格的成长股投资人"。
